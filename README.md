# VeTTor

Торрент-клиент для Windows без рекламы, без программ «в нагрузку» и без лишних файлов.
Сеть BitTorrent — библиотека [libtorrent](https://libtorrent.org) (та же, что в qBittorrent и Deluge),
интерфейс — PySide6 (Qt).

## Запуск

```
.venv\Scripts\pythonw.exe VeTTor.pyw
```

С нуля: `python -m venv .venv`, затем `.venv\Scripts\pip install -r requirements.txt`.

## Сборка EXE и установка

```
.venv\Scripts\pip install pyinstaller
.venv\Scripts\pyinstaller --noconfirm --clean --windowed --onedir --name VeTTor --icon build_assets\vettor.ico --collect-binaries libtorrent --hidden-import libtorrent --hidden-import yara --hidden-import pefile --add-data "vettor/analysis/rules.yar;vettor/analysis" --exclude-module tkinter VeTTor.pyw
powershell -ExecutionPolicy Bypass -File packaging\install.ps1
```

Программа ставится в `%LOCALAPPDATA%\Programs\VeTTor` (права администратора не нужны), появляются ярлыки
на рабочем столе и в «Пуске». Удаление — «Параметры» → «Приложения» → VeTTor.

## Возможности

- .torrent-файлы и magnet-ссылки (двойной щелчок, перетаскивание в окно, Ctrl+V) — загрузка начинается сразу.
- Лишние файлы (ярлыки, ссылки на сайты, реклама раздающего) и подозрительные файлы
  (`film.mp4.exe`, `codec_setup.exe` в раздаче сериала) не загружаются — об этом приходит уведомление.
  Окно выбора файлов можно включить в настройках.
- Проверка во время загрузки: каждый докачанный файл проверяется, заражённый удаляется,
  остальные файлы и раздача продолжают работать.
- Экономия места: архивы в раздаче (ZIP, RAR, TAR) распаковываются после загрузки, а сам архив
  удаляется прямо по ходу распаковки — на диске одновременно лежит примерно столько, сколько занимает
  распакованное, а не «архив + распакованное». Многотомный RAR (.part1.rar…) освобождается по томам,
  одиночный RAR — после распаковки (нужен WinRAR). 7z и установщики-репаки так не распаковываются.
- Проверка места до загрузки: если места не хватает, торрент добавляется на паузе.
- «Сжатие» — прозрачное сжатие папки средствами Windows (NTFS LZX), обычно 20–50% у игр и программ.
- «Проверка файлов» (этап 1 Cloud Threat Analysis): статический анализ любого файла без запуска и без отправки —
  хэши, тип по содержимому, цифровая подпись, устройство программы (импорты, секции, упаковщики, сведения
  о версии, самозванство), строки и индикаторы (адреса, опасные команды), сценарии, макросы Office, PDF,
  ярлыки, архивы (с проверкой файлов внутри и защитой от «бомб»), правила YARA, Microsoft Defender.
  Итог: Вредоносный / Высокий риск / Требует проверки / Низкий риск / Недостаточно данных, с уровнем
  уверенности и фактами, на которых он основан. История проверок, отчёт в HTML и JSON.
  Анализ идёт в отдельном процессе (лимит памяти 1,5 ГБ, 5 минут) — испорченный файл не уронит программу.
  Свои правила YARA: `%APPDATA%\VeTTor\yara\*.yar`.
- Очередь, пауза, принудительный старт, последовательная загрузка (смотреть во время скачивания),
  приоритеты файлов, перемещение, проверка, лимиты скорости для каждого торрента.
- Общие и альтернативные лимиты скорости, расписание.
- Шифрование, анонимный режим, прокси SOCKS5/HTTP, IP-фильтр (eMule .dat / PeerGuardian .p2p).
- Привязка к интерфейсу VPN: если VPN отключится, загрузки остановятся сами.
- Лимиты раздачи по рейтингу и по времени.
- Значок в области уведомлений, уведомления о завершении, светлая и тёмная тема.
- По желанию (в настройках): открытие .torrent и magnet-ссылок, автозапуск с Windows.

## Безопасность

От чего защищает клиент и как:

| Угроза | Защита |
|---|---|
| Вирус под видом видео (`серия.mp4.exe`, расширение за пробелами, символ U+202E) | `safety.py`: такие файлы помечаются красным, не загружаются по умолчанию, предупреждение показывается всегда |
| Исполняемые файлы и символические ссылки в раздачах фильмов и музыки | снимаются с загрузки, приходит уведомление |
| Вирус в докачанном файле | `guard.py`: файл сразу проверяется Microsoft Defender (медиафайлы — ещё и на спрятанную программу по заголовку `MZ`); заражённый удаляется и исключается из загрузки, торрент переподключается без его кусков — без перепроверки, остальные файлы не меняются |
| Запуск скачанной программы | метка «загружено из интернета» (Mark-of-the-Web) → проверка SmartScreen; подтверждение перед запуском из клиента |
| Ручная проверка | правый щелчок → «Проверить антивирусом» |
| Огромный или испорченный .torrent | файлы больше 20 МБ не открываются |
| HTML в именах и комментариях подделывает интерфейс | недоверенный текст выводится только как обычный текст |
| Путь `..\` в имени торрента | открываются только пути внутри папки загрузки |
| Кража пароля прокси из файла настроек | шифрование Windows DPAPI: расшифровать может только ваша учётная запись |
| Чужая программа передаёт ссылки в клиент | канал между копиями доступен только вашей учётной записи, данные проверяются |
| Утечка трафика мимо VPN | привязка к интерфейсу; при его пропадании сессия останавливается |

## Где хранятся данные

`%APPDATA%\VeTTor` — настройки (`settings.json`) и состояние торрентов (`resume\`).
Удаление программы: удалите эту папку и папку проекта; если включали связь с Windows —
сначала выключите её в настройках.

## Структура

| Файл | Что делает |
|---|---|
| `vettor/engine.py` | сессия libtorrent: добавление, очередь, сохранение, лимиты, VPN-привязка |
| `vettor/safety.py` | поиск лишних и опасных файлов в раздаче до загрузки |
| `vettor/guard.py` | проверка докачанных файлов и удаление заражённых |
| `vettor/antivirus.py` | вызов Microsoft Defender |
| `vettor/extract.py` | распаковка ZIP/TAR/RAR с освобождением прочитанной части архива |
| `vettor/unpacker.py` | когда и какие торренты распаковывать |
| `vettor/diskspace.py` | разреженные файлы, размер на диске, сжатие NTFS |
| `vettor/analysis/static.py` | статический анализ файла |
| `vettor/analysis/indicators.py` | признаки и итоговая оценка риска |
| `vettor/analysis/worker.py` | изолированный процесс анализа (лимиты памяти и времени) |
| `vettor/analysis/report.py` | история проверок, экспорт HTML/JSON |
| `vettor/analysis/rules.yar` | встроенные правила YARA |
| `tests/` | автоматические тесты: `.venv\Scripts\python -m unittest discover -s tests -v` |
| `vettor/winintegration.py` | ассоциации .torrent/magnet и автозапуск (только HKCU) |
| `vettor/ui/` | окна и виджеты |
